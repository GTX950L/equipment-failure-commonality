📂 松开鼠标，导入数据文件（支持 .csv / .xlsx / .xls）

1 数据

📂 点击选择文件，或直接把文件拖到这里
支持 .csv / .xlsx / .xls（自动识别表头）
💡 没有现成数据？点「加载示例数据」先体验。

2 打钩选择参与分析的列

📋 自动识别的表头（点开查看每列类型与样例值）
数据预览（前 5 行）
🔗 工序参数列（可多选，按勾选顺序形成链路）
🚨 哪些值算「不良」？
颜色含义：红 = 该路径 NG 明显偏多，蓝 = 合格为主。

3 出图

先在左侧选择好列，点击「🚀 生成桑基图」。
图上方工具条也能直接下载 PNG / 放大。
📖 读图方法：红色流从哪一层开始分叉，问题就集中在哪一层 —— 例如某个型号 + 某个档位 + 某个数值区间一路红到 NG。
